# 北京联通 Q5 (Amlogic S905L / P212 NAND版) Armbian 定制与调优总结

## 一、 核心问题与排查结论

1. **U-Boot 无限重启循环（Synchronous Abort `far 0x44000000`）**
   * **原因**：主线 U-Boot 2024.01 开启了严格的 LMB 内存保护，而旧版 `boot.scr` 尝试将 `uEnv.txt` 加载到 `0x44000000`（超出物理内存范围或覆盖保留区），导致 CPU 触发非法内存访问异常并不断重启。
   * **解决**：移除/备份 `BOOT` 分区下的 `boot.scr`，改用适配低内存的 `extlinux/extlinux.conf` 进行引导。

2. **1GB 物理内存仅识别出 407MB（实际硬件探测 512MB）**
   * **原因**：FIP 封装时使用了 `jethub-j80` 的闭源 `bl2.bin`，该固件在底层初始化 DDR3 时仅探测了 `Rank0: 512MB`（16-bit 单通道），未激活完整 1GB 寻址。
   * **解决**：改用支持 1GB/2GB 的 GXL FIP 配置（如 `libretech-cc` 或 `p212`），或从北京联通 Q5 原厂 NAND 线刷包中提取 `DDR.USB`（即 `bl2.bin`）替换后重新封装 U-Boot。

3. **Linux 音箱底噪与 Squeezelite 静音优化**
   * **原因**：声卡自动省电模式切换产生爆音，或未使用的输入/监听通道（`Mic`、`Mic Boost`、`Loopback`）开启导致底噪放大。
   * **解决**：禁用声卡 `power_save`，并通过 `amixer` 静音所有未使用的输入/环回通道，再用 `alsactl store` 固化状态（Debian 的 `alsa-restore.service` 为静态服务，由 udev 规则在检测到声卡时自动触发加载，无需手动 `enable`）。

## 二、 关键操作与命令速查

### 1. 无损替换 TF 卡主线 U-Boot（保留分区表与系统数据）
> 将新生成的 `u-boot.bin.sd.bin` 写入 TF 卡引导区（假设 TF 卡设备为 `/dev/sda`）：
```bash

sudo dd if=u-boot.bin.sd.bin of=/dev/sda conv=notrunc,fsync bs=512 skip=1 seek=1

```

* **方法 A（从盒子内置 NAND 提取，若内核已识别 `/dev/mtd0`）**：
```bash

```
* **方法 B（从原厂线刷包提取并封装主线 U-Boot）**：
```bash

./build-fip.sh p212 ../u-boot/u-boot.bin ../fip_output
```

### 3. 批量静音 ALSA 多余输入通道并永久保存（针对 Squeezelite）
```bash
# 1. 查看声卡编号（确认外接 USB 声卡或板载声卡对应的 card ID）
aplay -l

# 2. 扫描并静音指定声卡（以 card 0 为例）的所有输入与环回通道
CARD_ID=0
amixer -c "\$CARD_ID" scontrols | sed -E "s/.*'([^']+)'.*/\1/" | grep -iE "Mic|Boost|Line|Aux|CD|Beep|Loopback|Capture|Input|ADC|PGA" | while read -r ctrl; do
    amixer -c "\(CARD_ID" sset "\)ctrl" 0% mute > /dev/null 2>&1
    amixer -c "\(CARD_ID" sset "\)ctrl" nocap > /dev/null 2>&1
    amixer -c "\(CARD_ID" sset "\)ctrl" off > /dev/null 2>&1
    amixer -c "\(CARD_ID" sset "\)ctrl" Disabled > /dev/null 2>&1
done

# 3. 保存所有声卡混音器状态至 /var/lib/alsa/asound.state
sudo alsactl store
```

SWAP_ALGORITHM=zstd
EOF'

# 3. 重启 ZRAM 服务使配置生效

2. 优化内核虚拟内存交换倾向（sysctl 调优）

为了让 Linux 内核更积极地把不活跃的后台进程（如 Samba 守护进程、空闲的 Perl/PHP 内存页）压入高速 ZRAM 中，同时避免频繁唤醒压缩线程，建议将 vm.swappiness 调整为 150（内核 5.x/6.x 支持高达 200 的值，专为 ZRAM 设计）：

# 写入 sysctl 内存调优参数

vm.swappiness=150
vm.watermark_boost_factor=0
vm.watermark_scale_factor=125
vm.page-cluster=0
EOF'

# 立即应用内核参数
sudo sysctl -p /etc/sysctl.d/99-zram-opt.conf
